# Usman Heart Care Clinic Website

A responsive, front-end appointment website built with separate HTML, CSS and JavaScript files.

## Files
- `index.html` — Home, services, timings, clinic search
- `appointment.html` — appointment form with date/time validation and WhatsApp request
- `contact.html` — phone, WhatsApp and Google Maps contact page
- `style.css` — complete responsive styling
- `script.js` — menu, clinic search, appointment slots, localStorage and WhatsApp booking
- `assets/heart.svg` — simple site icon; no clinic pictures are used

## Appointment behavior
- Only Monday, Thursday, Friday and Sunday can be selected.
- Online slots are 30 minutes.
- Requests are stored in the browser's localStorage.
- A booking ID is generated.
- The visitor can send the complete appointment request to WhatsApp: 0341-4114536.
- This is a front-end website; it does not create a server-side database or automatically confirm appointments.
